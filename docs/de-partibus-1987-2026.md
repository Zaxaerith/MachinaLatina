# De Partibus (1987–2026)
## 《部件之治：科研微内核与记录服务》
> DRAFT · 2026-11-26。架空年代、产品和市场结局均为候选；不是已发布操作系统。

## 1987–1992：Sextaria S2 与 PARTES I
S1 的 48 位字、六槽指针和 F48 传统适合科研记录，但没有隔离机制。S2 候选增加字地址基址/界限保护、用户/监督模式和定时陷入。早期采用连续区段而非 Nova 的字节分页，节省页表却面临碎片、增长迁移和没有页级执行权限的限制。科研中心希望文件解释器、数值服务与排版程序能够独立升级；PARTES 将它们置于独立用户进程，微内核负责调度、隔离与消息。实际外设驱动依赖后续硬件机制。
## 1993–2000：专业工作站的服务化
候选 PARTES II 发展批量记录、文献目录与 F48 数值服务，地图数据不必等同无类型字节流。MODVLA 外部表示维持跨机记录一致性；RATIO 声明数值验收条件。微内核的消息复制及上下文切换会产生代价，低成本 Nova/ORDO-N 可能凭通用工具生态领先。大型数据的共享缓冲仍需生命周期及访问隔离标准，不能从 IPC 自动推导。
## 2000–2010：硬件衰退不等于系统死亡
Sextaria 专用 CPU 市场可能收缩，PARTES 可先移植到 Nova Maior、再到 Magna，保留消息与记录服务契约而重新编译内核和程序。两级页表、线性字节指针、系统调用编码与旧 48 位机器不同。M64 保护还未定义；F48 档案通过声明格式的软件转换保留，RATIO-I 不自动接纳 F48。NODVS、COS、RETE 进入独立文献与网络服务，并非新内核必须直接解析所有文档。
## 2010–2026：专业生态的另一种生存方式
候选 PARTES III/IV 进入科研服务器、档案馆、地理信息和科学可视化系统，以明确记录版本、数据模型与可替换服务作为竞争点。部分机构可能采用 LIBERTAS CODICVM 开放服务组件；许可证、市场份额及具体发行版尚未确定。服务重启不代表自动恢复事务，远程服务需独立安全协议；异构设备还需要 DMA 隔离与同步。PARTES 与 ORDO-N 共享语言工具并不等于共享内核；CVSTOS 之后可以继承部分消息隔离经验，却因移动设备权限和节能需求发展不同策略。
