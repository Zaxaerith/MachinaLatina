# Speculative Chronology / 1954—2026 架空技术年表

> **Phase XX 统一索引，2026-11-23。** 这是一条**架空历史的研究年表**，不是现实发明年代。历史事件和产品日期以 DRAFT 为主，不能仅因它们在同一表中出现而升格为 CANON。早期年代还包含真实比较锚点，明确标记 HIST。

## 连续时间线

| 年代（提议） | 等级 | 主要候选事件 | 导致的技术/制度问题 |
| --- | --- | --- | --- |
| 1954 | DRAFT | CVL-54 六位希腊/拉丁移位页；Machina XXXVI 36 位机器 | 6×6 位打包；字寻址与页状态 |
| 1957 | DRAFT | 科学计算语言 TRANFOR 原型 | 公式表达、旧字符集与语言标识符 |
| 1961–1962 | DRAFT | 自愿性的 CCL 编码与文字标准协调委员会拟议成立，由电信、机器/档案、科学/文献三组共同议事 | 发布的技术建议没有强制法律效力；十五席方案存在全球语言代表性不足的问题 |
| 1963 | DRAFT (推荐 TP1) | CVL-63 候选采用六位 CVL-54 数据 + 一位偶校验，改善通信可靠性 | 并未产生 128 字符的新编码；物理帧与校验失败恢复仍未定案 |
| 1964 | HIST | 现实 IBM System/360 出现，仅作八位字节历史参照 | 不意味着架空世界有 IBM 相同的型号 |
| 1965 | DRAFT | CCL 讨论 SHIFT-GRC 在偶数位错误下可能产生未检出的合法 TP1 码字 | 增加记录级校验与帧同步的动机；未解决所有损坏问题 |
| 1968 | CANON *方向* | CVL-68 八位直接希腊—拉丁文字成为主流发展路线 | 字符不需反复页切换；具体字节表仍 DRAFT |
| 1969–1972 | DRAFT | CCL 将编码 COD、线路 TEL、排版 TYP 和存档 ARC 的兼容性建议分开 | 采用同样的字符码不等于字体、文档格式、数值结果或机器码兼容 |
| 1968—1973 | DRAFT | Nova 32 位字节寻址研究家族与 XXXVI 并存 | 共同文档不等于机器码、数据格式、浮点兼容 |
| 1970–1987 | DRAFT | Ordo 批处理与交互系统前史 | 现代 P0–P2 不是历史内核 |
| 1973—1975 | DRAFT | 科研档案与新机厂商围绕文字/数值互换争执 | 分离文本、记录、数值与程序兼容等级 |
| 1975–1980 | DRAFT | 字符终端与矢量绘图路线 | 文字布局、几何及像素分离 |
| 1976—1978 | DRAFT | Sextaria-S0 48 位科学机提案 | 六个八位字符成字，但不自动获得文本密度优势 |
| 1978—1980 | DRAFT (S1/F48 R1) | 16 个 48 位寄存器、混合字/槽地址、38 位有效数 | 26 条候选指令；设备、中断和 ABI 未定 |
| 1979—1985 | DRAFT (MODVLA-I/R1 候选) | 模块接口/实现、逻辑记录与显式外部字节格式 | 本机内存布局、机器码、调用 ABI 与外部数据分别定义 |
| 1981—1983 | DRAFT | Nova Minor 廉价微机、希腊文 ROM 字形争执 | 能存储、能显示、能编辑、能打印是不同能力 |
| 1983—1985 | DRAFT (RATIO-I/R1 候选) | 科学计算契约语言：单位、明确 F36/F32、精确参考与绝对容差 | 数值正确舍入不等于通过误差验收；F48 候选另见 S1，RATIO I 未接纳 |
| 1983–1986 | DRAFT (LVDVS I) | 瓦片和精灵显示候选 | 复用图案以节省显示存储；主机 ISA 未定 |
| 1984–1990 | DRAFT (IMAGO) | 二维像素表面及有长度绘制命令 | 字形布局和驱动独立 |
| 1984—1987 | DRAFT | TABVLA 双文字桌面及出版系统 | 重音、气音、字符簇、输入法和打印 |
| 1984–1989 | DRAFT (Media) | 16 位程序员模型、24 位线性字节地址 | 图形内存与办公生态；ISA 未定 |
| 1988–1995 | DRAFT (Maior R1) | 32 位寄存器机、固定四字节指令 | 与 N1 二进制不兼容 |
| 1987–1992 | DRAFT (PARTES I) | Sextaria S2 字区段保护、微内核与类型消息 | 独立科研服务；实际设备接口未定 |
| 1988–1995 | DRAFT (ORDO-N I) | M32 保护扩展、4 KiB 页、进程与字节流 | 七项候选系统服务；无实际内核 |
| 1988–1991 | DRAFT | 其他书写社群质疑 CCL 的旧席位；1991 年虚构权限范围声明 | CCL 继续管理 CVL 历史码，不再假设有权单独登记全世界字符 |
| 1987—1990 | DRAFT | Sextaria 科研工作站与大众 Nova 生态竞争 | 专业精度和成本、桌面 API 和软件市场 |
| 1990—1992 | DRAFT | 全球字符身份讨论开始 | 八位 CVL-68 不足以覆盖世界文字 |
| 1993—1995 | DRAFT | 语义文档与定版页面技术分歧 | 可编辑性、精确印刷和资料保存 |
| 1992–1994 | DRAFT | 多文字社群筹备 CSM（世界书写系统共同体） | A/B/C 席位讨论全球文字的代表权，仍存在利益和资金不平等 |
| 1993–2005 | DRAFT (FIGVRA) | 定点屏幕三角形、深度测试、候选三维加速与主机 | 完整三维管线尚未定义 |
| 1995—1997 | DRAFT | COS 字符身份登记簿提案 | 抽象字符不等于网络字节 |
| 1997 | DRAFT | CSM 虚构 COS 字符身份原则性表决 | 文字身份与网络字节分离，尚未确定具体码位或变长格式 |
| 1998—2000 | DRAFT | NODVS 类型化超文本、LIGAMEN 引用 | 复杂科研文献与廉价网页的取舍 |
| 1998–2001 | DRAFT (COS-97/R1 候选) | 24 位字符身份、C24 固定三字节与 W1 变长交换方案 | 旧 CVL 文本可保留字节；全球字符分配与网络帧仍未批准 |
| 1998–2005 | DRAFT (network R1 candidates) | NODVS typed document records, LIGAMEN revisioned references and RETE application-layer exchange | Explicit COS encoding, bounded framing; directory, security and dynamic applications unresolved |
| 1998–2005 | DRAFT (Magna R1) | 64 位寄存器、48 位地址、可选 M32 模式 | 同指令格式不等于同 ABI；F64 未定 |
| 2001—2003 | DRAFT | 多文字域名与同形异码安全危机 | 展示名称、线路标签和脚本告警 |
| 2000–2003 | DRAFT | CCL/CSM 历史档案保存与国际域名分权争论 | CVL 转码、COS 字符登记、域名线路编码由不同机构协同 |
| 2004—2005 | DRAFT | 全球文字身份与旧 CVL 存储达成候选共存策略 | 显式编码声明、可审查转码 |
| 1999–2004 | DRAFT (SERMO I candidate) | 文献脚本演化为 FORMA 类型化文档构造语言 | COS 字符身份与原始字节分离，文档体与发布身份分开 |
| 1995–2005 | DRAFT (ORDO-N II) | Magna 迁移与 TABVLA 用户态桌面 | M64 ABI 待定 |
| 2005—2007 | DRAFT | LIBERTAS CODICVM 自由软件/档案运动 | 公开可维护源码、文件格式和设备控制权 |
| 2007—2009 | DRAFT | ORDO-N、PARTES、CVSTOS 三种系统家族构想 | 字节流、类型记录、移动权限、能耗 |
| 2007–2026 | DRAFT (Mobilis) | Nova 低功耗衍生、多核心与独立加速设备 | 共同 ISA 子集、不同设备/系统接口；具体扩展未定 |
| 2000–2010 | DRAFT (PARTES migration) | 科研服务由 Sextaria 移植至 Nova 后继 | 保留记录契约，不共享机器码；M64 ABI 待定 |
| 2005–2015 | DRAFT (ORDO-N III) | 商业与 ORDO-N LIBER 候选开放发行版 | 内核来源、许可待定 |
| 2007–2010 | DRAFT (CVSTOS I) | Mobilis M32、应用隔离、文档代理与能力授权 | 设备驱动与 ABI 未定 |
| 2011–2018 | DRAFT (CVSTOS II / owner-control debate) | 签名分发、后台预算、用户信任根候选 | 签名不等于运行授权，具体密码协议未定 |
| 2008–2012 | DRAFT (STEMMA) | 分布式源码世系、类型化对象和精确 COS 名称 | 摘要算法与传输未定 |
| 2010–2015 | DRAFT (FORVM CODICVM) | 公共托管、修改提案、审阅与镜像 | 认证写入协议未定 |
| 2011–2018 | DRAFT (FASCICVLVS) | 按发行者与目标 ABI 分发、依赖锁定 | 签名格式及加载器未定 |
| 2010—2012 | DRAFT | 多文字源码分发、跨架构包清单与版本控制 | COS 文件名与包名、来源和 ABI |
| 2005–2015 | DRAFT (SERMO II–IV candidates) | 服务器服务、可选客户端、能力句柄与异步任务的候选演化 | 被动 NODVS 不自动执行脚本，RETE R1 无写入或安全握手 |
| 2012—2014 | DRAFT | 云端科学计算与数值可复算性争论 | Sextaria 数学传统可脱离 48 位硬件存活 |
| 2014—2015 | DRAFT | 开源许可与手机签名启动/应用分发矛盾 | 读源码的自由与安装修改软件的权利不同 |
| 2005–2015 | DRAFT | 可编程图形与跨平台游戏引擎 | 着色器、资源同步与设备 ABI 待定 |
| 2015—2017 | DRAFT | 通用服务器与专用矩阵计算加速分化 | 混合精度、参考计算、并行归约 |
| 2018—2020 | DRAFT | 历史 CVL/COS 文献进入 AI 训练语料 | 原始字节、字符身份和 token 分词不能混淆 |
| 2016–2026 | DRAFT (CVSTOS III/IV) | 64 位移动系统、独立加速器与端侧模型 | M64 保护、设备安全及算力未定 |
| 2021—2023 | DRAFT | 拉丁—希腊科研语料优势引发公平与引用争论 | 全球语言覆盖、资料来源和科学责任 |
| 2024—2025 | DRAFT | 异构计算与可复核科研 AI 工作流候选 | 能耗、显存/互联、真正存在的文献引用 |
| 2026 | DRAFT | Nova 后继 CPU、矩阵设备与 COS/NODVS/RATIO 理念可能汇合 | 不是已研发的统一 AI 系统 |

## 本世界 CANON 与研究实现

**已确定的世界前提**仍只有古典拉丁语持续活用、希腊语的制度性学术角色、23 字母核心、双文字原生设计要求以及 1960 年代后期八位直接双文字路线。**每项具体技术名称/发布日期/厂家是否成立，需要单独核准。**

现实仓库研发（**不属于虚构年代**）：
- 2026-10—11：XXXVI、Nova、TRANFOR 与 Ordo Operum 的 Python 研究实验陆续加入 GitHub。测试记录证明特定代码在当时可执行，不证明虚构设备实际出现在 1954/1968 年。
- 2026-11-23：移除自动 CI 工作流，转向文档优先的世界观推演。
- 2026-11-23：Phase XX 汇总七十余年叙事，保留不确定性、技术成本和原始研究记录。
