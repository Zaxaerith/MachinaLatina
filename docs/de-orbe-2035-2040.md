# De Orbe (2035–2040)
## 《可计算之地球：从地图到科学世界模型》
> FUTURE SCENARIO / DRAFT · 2026-11-26. All dates, platforms and industry outcomes are conditional fictional scenarios. ORBIS expands the global visualization concept from Phase XXXV.

## 2035–2036：从空间档案到动态三维
GEOGRAPHIA、MENSVRA、PARTES 的数据传统进入 ORBIS。观测的坐标基准、分辨率、时间、缺测掩码和来源随版本保存。倾斜摄影、遥感影像、点云、网格及三维高斯等表示可能用于三维重建；视觉逼真不等于高程、拓扑或物理模型准确。全球统一一米网格不是工程目标，按任务分辨率与区域层级组织资源。
## 2037：校园和城市数字孪生
小范围设施模型结合独立水网拓扑、传感器、台账和计算服务。显示的水流动画不是流量测量。边缘节点处理高频本地状态，区域节点聚合必要数据，用户可检查实际观测年龄、权限和缺测。示例校园水量平衡仅为纸面模型，不是任何真实项目数据或控制方案。
## 2038：世界模型进入科学计算
TRANFOR 提供物理数值算法方向，MENTIS/MATRICES 学习代理模型与状态预测，MODVLA 描述服务契约，RATIO 提供数值误差传统。模型预测、估计状态、真实观测和渲染分离。每一预测需声明初值、边界条件、预报时效和不确定性；超出训练/验证范围时可拒绝或退回物理求解。RATIO I 的现有子集不因此增加语法。
## 2039–2040：分布式 ORBIS
推荐不同机构保留独立数据与区域模型，通过受控接口交换边界条件、观测和结果。无需单个巨型中央世界模型；时空分辨率、更新速度和模型适用性因任务而异。Nova Memoria 与 FIGVRA 负责阵列/可视化，Sextaria 提供候选精度服务，CVSTOS 保护终端授权，ORDO-N 和 PARTES 保留独立系统。MENTIS 提供任务工作区与可审阅报告而不直接控制现实设备。中央云、商业封闭模型以及较慢的采用速度均保留为替代路线。
## Boundaries
[Spatial R1](../specifications/ORBIS-spatiotemporal-R1.md) defines a bounded local raster fixture, not a global CRS. [World model study](../specifications/ORBIS-world-model-study.md) defines evidence distinctions and a water-balance paper case. No perfect digital mirror, no guaranteed predictive skill, no real-time whole-Earth simulation or actual hardware benchmark. C19–C25 remain open, as do global geodesy, secure federation, assimilation, full rendering, model training, hardware drivers and physical control. Next phase 2040–2045: conditional optical/electronic architectures, no assumed physical breakthrough.
