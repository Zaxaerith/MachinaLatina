# Historical Sources / 现实史实依据

This bibliography identifies **real** references that constrain or inspire the alternate history. Real-world dates, devices and standards must not be presented as fictional CVL product history.

## Computing and characters

1. **IBM Archives — IBM 704**. IBM documentation and corporate history on early scientific computing, including its 36-bit design and role in FORTRAN. https://www.ibm.com/history/704
2. **IBM Archives — System/360**. The System/360 family provides a real historical reference point for byte-oriented computer families in 1964. https://www.ibm.com/history/system-360
3. **The Computer History Museum — FORTRAN**. Historical information on the first FORTRAN implementation and its constraints. https://www.computerhistory.org/
4. **RFC 3629 — UTF-8, a transformation format of ISO 10646**, November 2003. Useful for studying byte compatibility and encoded text—not a source for our fictional CVL mappings. https://www.rfc-editor.org/rfc/rfc3629
5. **The Unicode Standard — Greek and Coptic / Greek Extended**. Relevant to Greek final sigma, combining accents, and the distinction between code points and glyphs. https://www.unicode.org/charts/

## Word lengths and competing architectures

- **DEC PDP-10 / 36-bit family:** historical precedent for 36-bit machines persisting into time-sharing decades. https://nssdc.gsfc.nasa.gov/nssdc/formats/PDP-10.html
- **Burroughs B5000:** 48-bit machine data word and a different architecture philosophy, **not** a six-byte CVL-68 machine. https://www.cs.uaf.edu/2010/fall/cs441/proj1/b5000/
- **CDC 6600:** 60-bit scientific-computing precedent; never equate word width to actual workload performance. https://www.cisl.ucar.edu/ncar-supercomputing-history/cdc6600
- **IBM System/360:** 1964 compatible byte-oriented machine family; a useful counterexample to assumptions of mandatory fixed science-computer word length. https://www.ibm.com/history/system-360

These entries are **real-world analogies**, not evidence of Sextaria, Machina Nova or invented Latin language vendors.

## Personal computing and desktop publishing (real history analogies)

- **Xerox Alto and Xerox Star** — bitmap displays and document-oriented GUI research; chronology does not imply an identical TABVLA system existed. https://computerhistory.org/press-releases/xerox-alto/
- **IBM PC 1981** — IBM's PC history, relevant to affordable personal hardware and the 8088's bus/architectural distinctions. https://www.ibm.com/history/personal-computer
- **Macintosh 1984** — Smithsonian collection for early Macintosh memory and GUI context. https://americanhistory.si.edu/collections/object/nmah_334371
- **Desktop publishing and PostScript/LaserWriter (1985)** — historical page description and print technology comparisons. https://archive.computerhistory.org/resources/access/text/2012/10/102746510-05-01-acc.pdf
- **Unicode Standard publication history** — historical 1990s text-standard chronology, *not* a fictional CVL successor by default. https://www.unicode.org/history/publicationdates.html

## Internet and worldwide scripts (historical comparisons only)

- **CERN and early Web:** real late-1980s/early-1990s hypertext/HTTP origins. https://home.cern/science/computing/the-birth-of-the-web/short-history-web/
- **RFC 1866 (HTML 2.0, 1995):** real text-oriented hypertext design history, not the fictional NODVS grammar. https://www.rfc-editor.org/rfc/rfc1866
- **RFC 2070 (1997):** real HTML internationalization. https://www.rfc-editor.org/rfc/rfc2070
- **W3C XML 1.0 (1998):** real structured markup and character handling. https://www.w3.org/TR/1998/REC-xml-19980210/
- **RFC 2044 / RFC 2279 / RFC 3629:** historical UTF-8 refinements; avoid anachronistically treating 2003 restrictions as original 1996 text. https://www.rfc-editor.org/rfc/rfc2044 https://www.rfc-editor.org/rfc/rfc2279 https://www.rfc-editor.org/rfc/rfc3629
- **RFC 3490 / RFC 3492 (2003):** real IDNA/Punycode domain-name standards; no claim that fictitious CVL networks use them. https://www.rfc-editor.org/rfc/rfc3490 https://www.rfc-editor.org/rfc/rfc3492
- **RFC 3986 (2005):** URI generic syntax and percent encoding, a technical comparator only. https://www.rfc-editor.org/rfc/rfc3986

## Free software, source control and mobile platforms (real historical analogies)

- **GNU project founded in 1983 and FSF in 1985:** dates to prevent treating the imaginary 2005 movement as a claim that real software freedom began then. https://www.gnu.org/gnu/about-gnu.html https://www.fsf.org/history/
- **GNU and Linux history:** real GNU project and 1991 Linux kernel beginnings. https://www.gnu.org/gnu/the-gnu-project.en.html
- **Git history (2005):** real history of version control and distributed development, not a fictional repository object-format proposal. https://git-scm.com/book/en/v2/Getting-Started-A-Short-History-of-Git
- **GPLv3 (2007):** real license event, not a fictional Latin license text. https://www.fsf.org/news/gplv3_launched
- **iPhone (2007) and App Store (2008):** actual mobile hardware and distribution shifts. https://www.apple.com/newsroom/2007/01/09Apple-Reinvents-the-Phone-with-iPhone/ https://www.apple.com/newsroom/2008/07/14iPhone-App-Store-Downloads-Top-10-Million-in-First-Weekend/
- **Android code release (2008):** real open mobile software development. https://opensource.googleblog.com/2008/10/android-open-source-cell-phone.html

All comparisons are **real-world anchors**, not claims that GNU, Linux, Git, iOS or Android historically existed under these names in the invented CVL ecosystem.

## Standards-development comparisons

8. **ITU-T International Telegraph Alphabet No. 2 (ITA2)** — letter/figure shift mechanisms offer a *real* precedent for fictional early page switching. Do not conflate ITA2's five-bit codes with CVL-54's invented six-bit codes.

## Research integrity rules

- Supply a specific primary document, official reference or reputable scholarly source when moving a historical point into a narrative.
- Record discrepancies and dates rather than inventing precise historical quotations.
- CVL-54, CVL-63, CVL-68, TRANFOR and Machina XXXVI are fictional project constructs.
- Latin technical coinages in this repository should be checked by qualified classicists before being described as idiomatic or historically attested.
