The central continuity is not a universal machine. It is the distinction between representation and meaning, native execution and exchange, data identity and authority, numerical output and evidence. The early need to distinguish Latin and Greek survives in COS character identity and model token vocabularies; scientific archives motivate numerical contracts; multiple OS families preserve independent control; user ownership becomes relevant when computation crosses domains. These are narrative connections, not proofs of historical inevitability.

The project has finished the first planned chronological pass through 2050, not finished its technical specifications. Concrete gaps remain: CVL/COS final registry and processing, M64 protection and native ABI, secure RETE and write protocols, digest/signature suites, RATIO expanded formats, full graphics/device contracts, model execution and distributed trust. Earlier code experiments remain archival. Future scenarios assume no solved dependency unless stated. Further research can deepen specific eras, competing products, institutions, developer culture, or repair actual spec gaps without adding more years. No real future claims, new code, CI, tag or release.
