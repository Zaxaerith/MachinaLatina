# De Nova (1981–2026)
## 从家庭微机到异构计算：通用计算机的胜利

> DRAFT · 架空技术史，2026-11-25。产品、年代、竞争结果皆为候选，不是实际发售、销量或性能记录。

## 1981—1989：大众化首先意味着成本下降

Nova Minor 采用独立的八位程序员模型与银行式扩展内存。学校和家庭不必为了输入拉丁文、希腊文而购买科研级 32 位机器；但是兼容 CVL-68 的键盘与文件并不意味着能运行 N1 机器码。廉价字符终端与位图桌面长期并存。

Nova Media 候选提升为 16 位程序员模型与 24 位线性字节地址。图形显示、磁盘、TABVLA 桌面与办公软件的需求逐步提高存储容量。显示屏与打印机对多调希腊语的支持仍需独立的字形、输入法和排版引擎。

## 1988—1995：真正的通用 Nova

Nova Maior 采用新 32 位寄存器架构，保留大端字节表示和 CVL 文件传统，但放弃 N1 累加器指令的直接兼容。16 个通用寄存器与固定四字节指令可以降低编译器后端的复杂性；指令密度也可能比变长编码差，不能宣称总体更快。MODVLA 的逻辑接口与外部记录契约为软件移植创造条件。老 N1 程序需要重新编译或独立模拟环境。

## 1998—2005：Magna 的 64 位转型

Nova Magna 候选保留 Maior 指令字段，扩展为 64 位寄存器和低 48 位字节地址。可选 M32 执行模式保护新一代存量应用的指令语义，但不能自动获得旧操作系统、驱动和应用 ABI。32 位和 64 位软件长期并存。COS 24 位身份可放入通用寄存器，而 W1/C24 的外部字节格式不因 CPU 字长而改变。

此阶段高端科学计算可借助更宽数值格式和独立协处理器，削弱 Sextaria 的专用优势。F64 数值标准未定，不能凭 64 位整数寄存器宣布精度提升。PARTES 的科学记录传统可以移植到 Nova 后继机，独立 F48 档案仍需转换与复算。

## 2007—2015：Mobilis 与移动系统

推荐的 Nova Mobilis 低功耗衍生家族并非桌面 CPU 简单降频。不同核心设计、设备集成、睡眠状态、热预算、固件和应用隔离推动新市场。共同 ISA 子集可促进工具链共享，但 CVSTOS 的权限及设备服务仍与 ORDO-N 不同；用户并不能直接运行任何桌面程序。

市场可形成高性能通用核心与低功耗核心两大阵营，但不必复制现实 x86/ARM 两套完全不同的 ISA 谱系。紧凑编码和独立 ISA 竞争分支都保留。LIBERTAS CODICVM 可以要求公开接口与可维护软件，却无法单凭开放源码保证设备启动权。

## 2015—2026：CPU 不再包办所有计算

服务器和 PC 的 Nova 后继核心处理通用任务，图形和矩阵设备承担专用负载。MODVLA 明确外部数据结构，RATIO 区分数值复算与科学可信度，SERMO/NODVS 提供报告和网络界面。多核心一致性、内存共享、加速器接口和低精度数值格式需要独立标准。共同 COS 文本标识也不意味着训练 token 一致。

到 2026 年，推荐设定是 Nova 成为主流通用架构生态，Sextaria 保存科学档案与数值传统，而非一个厂商垄断整个计算文明。主流地位、具体型号和产业份额仍未冻结。
