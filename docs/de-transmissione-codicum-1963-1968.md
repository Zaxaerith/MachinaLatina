# De Transmissione Codicum (1963–1968)
## 《通信革命，而非第三套字母：CVL-63 的架空历史》

> **DRAFT / 架空技术史提案（2026-11-23）。** 全部人物、联盟、事件、产品和经济争论均属虚构。本文推荐 CVL-63 的通信规范路线，不暗示已经获准成为 CANON。

## 为什么 1963 年可能没有自己的七位字符集？

在现实世界，七位 ASCII 以 128 个字符码值成为重要标准。但本世界已有一套能处理希腊语和拉丁语的六位页切换系统，而且 36 位科学机已积累软件与磁带。对 1963 年的电话电报运营商而言，保存已有字符码意味着无需重新制作整套字母表，不用让大学修改数十万行程序，只须改进接入线路和校验处理。

对于学术用户而言，这项妥协也很不完美：两套字符之间仍要使用 SHIFT；误传 SHIFT 可能把希腊文变成一串合法但错误的拉丁字符；旧终端依然无法表达全部古典多调希腊语。这些缺陷为 1968 年的直接八位编码留下真实动力。

## 五年技术史的候选链条

**1963 — 线路保卫战。** 建议称作 CVL-63/TP1 的七位传输单元出现：六位承载 CVL-54/P0 原数据，第七位计算偶校验。一个七位单元只承载一个六位代码；高位不是新的文字身份。这套技术可以适用于七轨带等介质，也可以转而成为串行连接中的数据单元，但实际线路结构并未确定。

**1964 — 硬件分歧。** 一部分设备公司支持奇偶校验、外部记录界限和可检测错误；大学要求随机查找文本时不需重新读取所有前面的 SHIFT。校验的是位完整性，**不是**字母语义或语言页状态。若丢失一整个 SHIFT 而所有剩余符号校验正确，错误可能传播到整个记录。

**1965 — 一次损坏的论文（虚构）。** 一家天文台收到七位传输的希腊文星表：某个 SHIFT-GRC 原本应当启用希腊字母页，却在传输中发生两位反转，恰好成为另一条合法偶校验的控制代码。通信运营商称线路符号“校验通过”，科研人员却发现星表标题被解错。这个故事解释了为什么简单奇偶校验无法替代应用级字义检查；它不是真实历史的事故。

**1966 — 新学校的需求。** 新一代科学教材需要混合拉丁小写、希腊小写、气音、重音和更多数学符号；现有 CVL-54/P0 终端仍局限于基本大写文字。增加校验位并不增加字符容量。科研机构开始要求“每一种字母都拥有稳定的直接代码，而不是依赖当前打印机上的语言页”。

**1967 — 真正的标准战争。** 电信行业倡议继续使用 TP1，学术出版和新微电子厂商推崇更贵却更容易编程的八位原生代码。旧 XXXVI 仍然可以接入 TP1 网络；新 Nova 一类机器需要网关：先检验七位传输单元，解码六位 SHIFT 字符，再输出 CVL-68 的直接八位字符。这是文本级互通，并不意味着旧设备能够运行新机器码。

**1968 — 八位直编码胜出。** 在本项目已有的 CANON 方向中，CVL-68 逐渐成为原生文字的主流方向；CVL-63/TP1 仍可多年用于远程测站、廉价电传和老式档案系统。两种技术并存并非失败：新计算机简化日常文本处理，旧线路在价格和现有设备投资的压力下缓慢退出。

## 这一选择怎样改变以后的计算机史？

1. **更少无意义的格式迁移。** 1954 到 1963 并未出现全新字符身份和磁盘文件编码，所以 XXXVI 存量机器无需为了网络接入把内存数据改成七位。
2. **1968 成为真正的断点。** 八位 CVL-68 需要字符身份、程序、存储设备、终端和代码工具链的真实适配，而不是所谓“只加一位校验”。
3. **未来仍有旧链路。** 即便 1980 年代的家用机原生八位，远程科研、政府部门和工业设备仍有理由维护六位数据/七位物理记录转换；直到国际互联网迫使协议层明确编码声明。
4. **希腊学术机构的压力被保存。** 通信运营商没有因为 1963 年奇偶校验获胜就满足所有学术文字要求；多调希腊文一直是日后 CVL-68 RC1 学术扩展的动机。
5. **架空世界不需要自己的 ASCII 克隆。** 这条历史的独特性是标准化机构先解决“传输可靠性”，再在 1968 年面对“字符身份”，不是把现实七位 ASCII 按年份换名。

## 史实/假想边界

- **HIST:** 真实 IBM 七轨磁带六条数据轨加校验轨；ITU ITA2 电传存在字母/数字移位；现实 1963 七位 ASCII 标准存在。
- **DRAFT:** CVL-63/TP1、其偶校验和制度历史、天文台事故、电信与大学竞争以及 1968 年后的退出速度。
- **CANON already adopted:** 本世界从一开始具有希腊—拉丁双文字计算需求、1960 年代后期八位原生直接编码成为主流方向。
- **Modern research:** 现实 GitHub 上的 Python XXXVI/Nova 实验不等于架空 1963 年有已发布的硬件或转换设备。
