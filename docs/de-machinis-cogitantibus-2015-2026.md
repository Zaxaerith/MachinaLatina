# De Machinis Cogitantibus (2015–2026)
## 《会思考的机器：异构计算、全球文字与人工智能》

> **DRAFT 架空技术史，2026-11-23。** 文中假想的研发机构、标准、市场事件及年份不是真实历史，也不等于项目 CANON。HIST 标注的现实史实只是技术约束与比较。没有发布模型、加速器、代码或 CI。

## 序章：三种机器字长，如何变为三种计算传统？

Machina XXXVI 的 36 位六字符分组、Nova 的八位字节商业机器、Sextaria 的 48 位科学计算提案，曾分别代表不同的硬件和制度利益。到 2026 年，合理的结局不是三种原始 CPU 仍占领市场，而是**旧硬件消亡、兼容需求和软件理念延续**。

Nova 的后代可能演化为通用 64 位服务器；XXXVI 只剩科学档案、模拟环境和历史资料；Sextaria 的宽数值哲学转移到科学库、混合精度运算和专用验证程序，而不是一颗固定 48 位张量处理器。RATIO 的误差契约、MODVLA 的模块与数据类型、COS 的字符身份、NODVS 的结构化文献，都有机会成为这场 AI 革命的历史遗产。

## 第一幕（2015—2017）：48 位机器退役，精度思想没有退役

**DRAFT 2015：** 一所天文与地理测量机构决定减少 Sextaria 专业机器的采购。芯片制造规模、存储接口、通用系统软件和能耗令 48 位专有 CPU 越来越难维护；但是它的科学数据规范、数值误差报告和长期磁带档案不能随 CPU 一起丢弃。

**DRAFT 2016：** 为了进行神经网络计算，数值研究人员将工作分成两个领域：训练用的高吞吐矩阵处理与科研核对用的高可靠数值计算。低精度乘法、更宽累加、软件数学库或确定性归约都可以成为竞争方案。

特别不能声称：原来的 Sextaria 必然使用某种 F48 标准，因此它的后继 GPU 就拥有 48 位张量核心。**此前 F48 从未正式规定，Tensor Core 不是普通 CPU 字长简单加宽。**

**DRAFT 2017：** 候选的 RATIO 式科学工作流开始要求声明矩阵算子的精度、舍入、归约顺序和误差界；同一模型在不同设备上取得统计等价结果，不保证每一位数据完全相同。

## 第二幕（2018—2020）：旧文字第一次成为训练资料难题

**DRAFT 2018：** 一所跨文明学术图书馆试图把 CVL-54 打包档案、CVL-68 双文字论文、COS 全球资料和 TABVLA 文档送进大型语料库。数据完全到达并不保证内容正确：旧编码必须按原有页状态解码，希腊重音与气音不能被无声丢弃。

**DRAFT 2019：** 语料负责人发现，同样写着 Latin A 和 Greek Α 的字形，实际上可能是不同的字符身份。把它们合并可能破坏数学变量、书目检索、程序标识符和参考资料；只保留字节不注明文字标准同样会出错。

**DRAFT 2020：** 图书馆建立三层存档：原始文件及许可，经过严格解码的 COS 字符身份序列，以及专供模型使用的词片或字节 token 序列。三个对象必须有独立版本、来源、转换错误报告和撤回机制。

一个全球文字登记号不等于模型 token；原生支持希腊文字不意味着会自动理解亚里士多德的哲学或懂得地理学中的数学推导。编码规定文字如何被识别，机器学习仍受数据质量和模型训练影响。

## 第三幕（2021—2023）：两千年的高等学术地位成为偏见

**DRAFT 2021：** 一套面向大学的模型在拉丁工程说明与希腊数学文献上表现出色，却在中文地名、阿拉伯文手稿和低资源语种上存在较高错误率。文化机构要求公布训练样本的语言分布、来源授权与文字转换缺陷。**这是教育和资料分配的历史结果，不是拉丁语或希腊语天然更适合推理。**

**DRAFT 2022：** 架空的公众对话式助手进入市场。工程界习惯它用拉丁术语描述设备操作，学术界希望直接输入希腊符号和公式，而全球使用者要求它尊重当地语言。模型内部计算的是向量，不是一个能被人读取的“拉丁语思维过程”。

**DRAFT 2023：** LIBERTAS CODICVM 运动围绕 AI 再次分裂：可以查看推理代码、可以下载模型参数、能审计训练数据、具有使用和修改设备的权利，是四件不同的事情；是否符合自由软件传统不能只看营销中的“开放”字样。

## 第四幕（2024—2025）：真正的加速器战争

**DRAFT 2024：** 通用 Nova 后继 CPU 负责操作系统、网络和数据准备，矩阵加速器承担大量模型计算。厂商不再按“机器字长最大”比较性能，而是竞争显存和带宽、互联、混合精度、系统冷却及软件支持。Sextaria 的名声若仍在，更多来自可靠数值工作流与科学模型审核，而不是老式 48 位总线。

**DRAFT 2025：** NODVS 资料节点与 RATIO 数值契约被提议用于区分四种输出：模型生成的叙述、可真实检索到的文献、可独立执行的计算和由人审定的科研结果。引用一个格式正确却不存在的资料节点，不能视作已得到证据。

模型可以使用混合精度加速，但精密地学、天文学和统计模型仍可能要求高精度对照；训练速度与科学结论的可信度不是一个变量。

## 第五幕（2026）：三条架构思想重新汇合

想象一台架空的 2026 年科研工作站：
- **Nova 64 位后继**运行现代操作系统；没有理由宣称它仍执行 Nova-N1 机器码；
- **异构矩阵加速器**处理大模型训练与推理，使用任务适合的混合精度，而不是凭空继承未定义的 F48；
- **COS** 保存世界语言的文字身份；原始 CVL-68 档案仍需明确转码；
- **NODVS/LIGAMEN** 提供类型化文献、数据节点和可验证的链接；
- **MODVLA、SERMO、RATIO** 的候选传统分别影响系统接口、文本/网络操作及数值契约，均不代表现有编译器已经实现；
- 面向公众的 AI 助手可以同时处理拉丁工程术语、希腊数学和世界其他文字，但必须验证来源，不可仅凭流畅措辞制造权威。

### 这个 2026 年世界仍有六场争论

| 领域 | 解决方向 | 不可忽视的代价 |
| --- | --- | --- |
| 异构计算 | 通用 CPU + 训练加速器 + 高精度核验 | 能耗、带宽、成本和精度差异 |
| 世界文字 | COS 抽象身份 + 严格旧码转译 | token 分配和语料不平等仍然存在 |
| 科学证据 | NODVS 可追踪引用 + 实际数据验证 | 引用失效、模型误引、数据访问权 |
| 软件自由 | 分开讨论代码、模型权重、数据和设备 | 商业许可、安全和隐私权 |
| 学术语言 | 拉丁/希腊传统与全球多语并行 | 历史文化特权可能造成模型偏见 |
| 科研可靠性 | RATIO 式精度和溯源契约 | 数值/统计可复现不等于逐位一致 |

## 结尾：不是古罗马人发明了 GPU

我们保持物理学、计算复杂度、半导体经济学的大体约束。古典语言传统改变的是早期编码和教育制度的选择，随后不断累积为机器、操作系统、版权、科学记录和 AI 语料的不同历史。**语言改变了标准与机构的演化路径，而不是让某种 CPU 自动更聪明。**
