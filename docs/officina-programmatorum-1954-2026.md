# OFFICINA PROGRAMMATORVM (1954–2026)
## Phase XLVI · 程序员的工作台

> DRAFT / NOT CANON · 2026-11-27. Fictional workflows and product names are proposals, not historical shipments. No editor, terminal driver, IDE, debugger, protocol, CI or executable code is added. Inherit Phase XLIV museum configurations and XLV language families.

## 1954–1963: paper and batch
M01 XXXVI programmers prepare formula sheets, instruction/address listings and punched media, then submit jobs to operators. A 36-bit word has exactly twelve octal digits; octal is convenient for word inspection and a 15-bit word address has five octal digits. A conceptual printed listing identifies word addresses, not byte offsets. Paper tape transport, operator scheduling and diagnostic hardware are not defined by P0 EMIT. Early 1954 exhibit uses machine code, not a shipped TRANFOR compiler. Modern MXA examples illustrate later assembly research.
CVL-54 text displays need the correct initial page and shift history. A tape splice can change how following codes decode. Retain original words, packing, starting state and record boundaries; avoid arbitrary byte edits.

## 1964–1978: interactive terminals
M02 Nova N1 80×24 terminal is a candidate configuration, not a terminal protocol. The CVL-63 transport parity bit does not add character identity; CVL-68 native letters remove basic Latin/Greek shift overhead in storage. Terminal input mode is distinct from output decoder state and from case shift. A terminal can display uppercase letters yet lack combining glyph rendering.
Proposed line editor terminology: LINEA (line), INSERE (insert), DELE (delete), QVAERE (find), SCRIBE (write), FINIS (finish). These are menu/command labels only, not a shell grammar. Time-sharing and full-screen editing require suitable successor OS, terminal control and memory, not N1/P0 by fiat.
A Sextaria lab can display twelve hexadecimal digits or sixteen octal digits for a 48-bit word. Nova byte dump displays two hex digits per octet, aligned 32-bit words as eight digits. Address-unit metadata is always visible.

## 1979–1992: local editors
M04 DOMESTICA D1 has 48 KiB installed RAM and separate ROM/video store; small ROM monitor or line editor is plausible, not a full modern IDE. M06 D2 has 512 KiB and separate video RAM; TABVLA graphical workspace and SCRIPTVRA editor are plausible products. M07 scientific workstation can host numeric diagnostics and symbol tables after toolchain support. A display is not proof of a complete GUI.
MODVLA's INTERFACIES/CORPVS split encourages interface browsers and compiler diagnostics that distinguish source errors, external record errors and target ABI failures. RATIO tools show represented versus reference values and physical units. TRANFOR libraries use batch listings and numerical traces. A debugger cannot assume every CPU has breakpoint hardware, stack unwinding or single-step facilities.

## 1993–2005: integrated workbench
Propose OFFICINA as a generic Latin name for integrated development environments, not a registered brand. M08 Maior and M09 Magna are candidate host machines. Optional panels: FONTES (source), INTERFACIES (interfaces), NVNTII (messages), MEMORIA (memory), VARIABILIA (variables), PVNCTA (breakpoints), EXITVS (output). These provisional labels are not a linguistic standard.
COS-era editors separate bytes, CIDs, visible clusters, glyphs and source tokens. SERMO authoring can display a typed NODVS preview without executing arbitrary records. Compilation, launch and publication are distinct commands. Source navigation needs compiler-produced source mappings tied to the exact revision; optimized values may be unavailable.

## 2006–2026: networked and heterogeneous tools
STEMMA supports revision-aware review, FASCICVLVS target manifests, FORVM CODICVM collaboration. The IDE selects target ISA, ABI, compiler and host service profile independently. Cross-target build does not imply local execution. ORDO-N process debugger, PARTES service inspector, CVSTOS scoped application debugging require distinct adapters. Remote debugging requires explicit authorization and secure transport; no wire protocol specified.
MENTIS can suggest code, explain diagnostics, prepare patches or propose a numerical experiment. It must distinguish suggestions, executed operations, retrieved evidence and user approval; access to source does not grant arbitrary terminal commands, credentials or publication. Scientific verification via RATIO is independent of model-generated confidence.

## Culture and competition
A cheap school editor favors small memory and simple commands; scientific labs favor Greek notation, provenance and numeric displays; commercial teams favor graphical debugging and refactoring. Latin tool labels may remain widespread, while Greek and other languages are supported by local communities. No forced universal keyboard or IDE. A modern source file may have a Latin grammar and Greek comments without being a separate language. Greek identifiers require an approved lexical profile.
