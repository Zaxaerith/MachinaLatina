# ORBIS World Model — Observations, simulation and forecast evidence
> FUTURE SCENARIO / DRAFT · 2026-11-26. Candidate 2035–2040 architecture, not an implemented physical model, trained network, validated forecast or complete Earth replica.

## 1. Separate representations
Observation: measured signal or derived observation with sensor, calibration, timestamp, coverage and uncertainty. Scene: mesh, point cloud or neural radiance/3D Gaussian representation for rendering; view synthesis quality is not a metric of geometric accuracy or physical state. State: declared variables, units, support volume/area, time and uncertainty. Transition: physics solver or trained surrogate, versioned inputs, boundary/initial conditions, forcing, time step, assumptions and domain limits. Forecast: predicted state for a valid time conditional on model and forcing, never an observation. Decision: separately reviewed action, not automatic execution of a forecast.

Observation update may alter an estimated state through an explicit assimilation algorithm. Retain pre-update estimate, observation, method and posterior estimate as distinct revisions. No automatic overwrite of raw data. A learned transition may be constrained by conservation, but a conservation check alone does not establish predictive skill. Rendering may be asynchronously updated and visibly stale; display timestamp and resolution separately from simulation time. MENTIS assists selection and explanation; it is not itself a universally valid physics solver.

## 2. Bounded water balance fixture
For a hypothetical campus water-supply zone, use a well-mixed storage volume, a 15-minute step and fixed integrated input/output volumes for the step. Storage S0=100 m3, inflow=12 m3, metered demand=9 m3, estimated leakage=1 m3, no other flux in this toy boundary. Predicted S1=102 m3. Next independent measured storage=101.5 m3 with stated illustrative measurement interval ±0.4 m3. Residual prediction minus observation=+0.5 m3. An illustrative predeclared residual threshold |r|<=0.4 m3 fails, but this does not by itself prove a leak or quantify total predictive uncertainty. Measurement interval is not the model uncertainty or a confidence probability. A real network needs pressure, flow, topology, time synchronization, uncertain leakage, model errors and sensor quality. No actual campus data used. No automatic physical valve action in this profile.

For a candidate balance audit, record exact reference arithmetic, units, solver format/order, numerical tolerance separately from measurement and model residual, and actual execution status. Existing RATIO-I accepts limited scalar F32/F36 source; no array/assimilation syntax or F64 acceptance is implied. F48/F64/R0 and neural matrix formats are distinct. Example computed on paper only; do not mark CALCVLATVM. If forecasting an interval, record forecast horizon, stated confidence semantics if known, calibration and evaluation against independent observations. Do not invent uncertainty values where missing; flag unknown.

## 3. Multi-resolution and edge/cloud
Local sites keep detailed sensor data, building models and fast control where independently authorized. Regional nodes exchange selected observations and model boundary conditions; larger-scale services aggregate coarser states. Each interface declares spatial support, time window, units, transformation, freshness and ownership. Local measurements may not be uploaded merely because an ORBIS network exists. Failed/late updates retain last known state with age and uncertainty; no fabrication of real-time data. A federated model is not a single global simulation clock or globally consistent snapshot. Cross-region solver coupling, clocks, security, availability and conflict resolution are future work.

Memoria may hand off bounded arrays to FIGVRA, MATRICES or Sextaria engines under explicit ownership. Neural rendering and physics kernels have different accuracy requirements. Use separate validation: visual quality, independent geometry/control points, numerical convergence, physical residual/conservation, prediction on held-out times/regions, uncertainty calibration. No one score proves fidelity. A digital twin can be useful for a particular asset and task despite incomplete coverage; a world model can predict a process without photorealistic rendering.
