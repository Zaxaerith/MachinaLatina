# Conventus Scripturarum Mundi (CSM)
## 世界书写系统共同体 · 章程候选（1994—2005）

> **FICTIONAL CHARTER / DRAFT · 2026-11-24。** CSM 是虚构国际字符治理组织，COS（Codex Omnium Scripturarum）是其候选字符身份登记规范。二者不可混同。章程无实际法律效力，不触发任何 GitHub 项目 CANON 改动。

## I — Mission and limits / 使命与边界

CSM 以公共程序讨论世界书写系统的抽象字符身份、跨语言字符名称、稳定编号与版本维护，以及输入来源和公开异议。

CSM 不具有独立决定以下事项的权力：各国拼写规则、地方字符集的废弃、CVL 原始字节重写、所有网络协议、域名注册、字体字形及国家采购。

抽象字符不等于字形、存储字节、显示顺序、单词、语言或人工智能的内部 token。

## II — Constituent chambers / 会员与投票代表

| 组别 | 席位 | 社会功能 |
| --- | ---: | --- |
| A — Script Communities & Users | 8 | 语言使用者、文字社区、教育出版和实际书写组织 |
| B — Implementers & Standards | 6 | 设备软件、字符库、输入法和标准化技术 |
| C — Archives, Education & Public Interest | 6 | 研究机构、图书馆、公共档案、可访问性与教育 |
| **Total** | **20** | **不声称代表每一种世界文字** |

同一机构仅能拥有一席；共同控制的子公司和关联组织不得为额外投票权重复注册。委员身份、赞助和关联利益应公开。席位任期、跨地区配额和选举程序仍未设计；特别是 **八个 A 组席位不是八种固定文字的所有权**。

对于一项直接影响特定文字的申请，必须邀请该语言/文字社群进行额外技术审查，并记载缺席与反对意见；这不能以普通 A 组赞成替代。差旅和田野调查预算可通过公开补助支持小型社群。

## III — Candidate application process / 字符提案

1. **Petitio**：提交提案、实际书面样例、地区与历史使用证据、字形和字符身份差异、拟议名称及已有编码对照。
2. **Consultatio**：相关文字社群评估；避免把活语言习惯交给不使用该文字的专家单方面决定。
3. **Comparatio**：检查是否已存在字符身份，区别新字符、字体变体、连写与规范化。
4. **Experimentum**：记录实现成本、文本检索、历史转换和潜在同形异码风险，可附计算验证但不要求模拟器或自动 CI。
5. **Obiectio**：公开评论、申诉和多数/少数说明。
6. **Suffragium**：按照章程表决的是发布**字符身份建议**，而非自动生成网络编码。
7. **Editio**：公布稳定版本、已分配或未分配的编号及转换限制；不存在的具体编号不得由会议叙事臆造。
8. **Recursio**：纠错与上诉过程必须保护既有编号的稳定性，变更不得静默重新分配已广泛使用的字符身份。

## IV — Quorum and votes / 法定人数与通过条件

- 总席位：20（A=8，B=6，C=6）。
- 法定人数：总出席至少 16；其中 A 至少出席 6、B 与 C 各至少出席 4。
- 赞成阈值：在实际 **yes+no** 有效票中，赞成至少 2/3，即 yes ≥ ceil(2×(yes+no)/3)；弃权计入出席但不计入赞反。
- 文字使用者保护：A 组必须至少有 **5 张明确赞成票**，不能利用弃权降低这一要求。
- 直接受影响的社群未实际参与审查、且代表性不足时，会议应该延后决定并公开解释；即使赞成票够也不能宣称完全代表该社群。
- 本章程发布的建议不自动获得地区法定标准、互联网线路规范或软件实现地位。

这是一套**虚构的编辑方案**，不对应真实 Unicode、ISO 或 ITU 的表决规则。

| 事项 | 建议主责 |

| CVL-54 旧页切换、XXXVI 打包字和历史字节记录 | CCL 旧码/档案 |

| CVL→COS 可靠迁移、不可逆与证据记录 | CCL/CSM 联合转换组 |
| NODVS/RETE 内容、线路码与域名 | 独立网络工作组 |
| 字体、输入法、复杂排版 | 各文字社群及专业出版/排版机构 |

**原始 CVL-68 的 41/80 等字节不是 COS 码位**。负责字符身份的委员会不得因此直接修改文件字节或替网络协会决定完整线路协议。

## VI — Historical source integrity / 历史档案保存

每份转换建议至少应规定原始 CVL 源格式及版本、源记录与页状态、可知的 PAD/EOT/传输信息、转换错误、输出 COS 字符和编码标签，以及原始字节能否恢复。转换失败不应通过静默舍弃字母或希腊气音解决。面向搜索的衍生文本可以另存，但不能默认覆写原档。

## VII — Funding, public access and conflicts

提议通过透明机构会费和公开资助支付秘书处、语言调查、无障碍评估和历史档案转换研究。赞助商不得购买额外票数；技术文件、投票和利益冲突至少应当公开，具体许可与开支制度仍属 DRAFT。

CCL 与 CSM 均无法替各国立法；实际 repo 的 CC BY 4.0 文档许可和 MIT 代码许可不因虚构的 CSM 章程而变化。

## VIII — Status and options

**CSM 是否成立、是否于 1994 年采用这套章程、1997 年的建议是否发布，都保持 DRAFT。** 未定项包括特定地区/社群参与办法、席位任期、预算额度、专利许可条款、COS 字符编号大小和任何网络字节分配。
