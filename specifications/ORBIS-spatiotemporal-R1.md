# ORBIS Spatiotemporal R1 — Bounded raster records and observation identity
> FUTURE SCENARIO / DRAFT / NOT CANON · 2026-11-26. Candidate 2035–2040 scientific spatial contract. No implemented GIS, global CRS registry, satellite service or deployed digital twin.

## 1. Spatial identity
A dataset has an authority-scoped stable object identity and immutable revision, with distinct observation time interval, publication time and validity interval. The authority namespace is not itself authentication. A later registry must define CRS, axis order, horizontal/vertical datum, transformation method, epoch and uncertainty. No assumed common geodetic datum across regions. R1 deliberately limits the concrete fixture to a single declared local Cartesian grid in metres, x east, y north, z elevation relative to a declared local vertical reference, no geographic degrees or reprojection. Origins and cell sizes are exact signed/unsigned integer millimetres; use checked wide arithmetic. Time instants are signed 64-bit seconds from a declared continuous epoch; conversion to civil time needs an explicit leap/calendar policy, not specified here. Observation intervals are half-open and distinct from forecast valid times.

## 2. Raster tile profile
A tile is identified by dataset/revision, grid level, row and column tile indices and band. Each full tile has 256×256 cells; levels use powers of two times base cell size, same origin, indices nonnegative. A complete domain has explicitly declared extent; outside-domain cells are marked missing. Grid metadata and tile indices determine northwest corner x0,y0. Cell (r,c) center = (x0+(c+1/2)d, y0-(r+1/2)d), with row increasing south. d is positive cell size. Compute using rational arithmetic where needed. Pixel-is-area, not point. Coarser levels require explicit aggregation method and provenance; resampling is not an observation. No silent mixing of grids, epochs, bands or vertical datums.

Payload: 65536 big-endian signed 32-bit elevation values in millimetres, row-major, followed by 8192 validity-mask octets, MSB first (1 valid, 0 missing). Invalid cell value bytes canonical zero; valid zero is allowed. Exact length 270336 octets (264 KiB). Declared uncertainty belongs to observation metadata or a separately identified uncertainty layer, never inferred from storage quantization. Required logical metadata: dataset and revision, grid/CRS definition identity and revision, band/unit, observation interval, publication time, source references and processing recipe, valid-data mask, uncertainty method and limitations. R1 does not assign canonical metadata bytes or hashes, compression, on-disk catalogue, wire protocol or security scheme. Byte length and mask validation precede use.

Example at d=10 m, northwest (1000 m,2000 m): row 2 column 3 center (1035 m,1975 m). First two valid heights 100.000 m and 100.250 m are encoded 00 01 86 A0 and 00 01 87 9A; first mask byte C0 if remaining six cells are missing. Invalid samples are not zero-height observations. One tile covers 2.56 km × 2.56 km. A tile is a bounded record, not an entire planet.

## 3. Scale cost
For illustration approximate Earth's surface area as 510 million km², count ideal equal-area cells (not a feasible literal single Cartesian grid). At 1 m nominal resolution ~5.1e14 cells, one four-octet band ~2.04 PB decimal, before masks, overlap, indices, time, or other data. At 10 m ~20.4 TB, at 100 m ~204 GB. One validity bit per cell adds 1/32 of the 32-bit band size. Repeated snapshots multiply capacity; selective updates, regional levels, compression and derived caches have workload-dependent costs. A real global grid must handle curvature, poles, seams and differing observation coverage. These are arithmetic scenarios, not actual ORBIS storage estimates or forecasts.

## 4. Service boundary
PARTES record identity informs metadata but its 1536-octet IPC envelope cannot carry a 264 KiB tile in one call. A future adapter may return metadata and separately grant bounded Memoria buffers; existing PARTES-I does not define handle transfer or shared memory, so this is a new logical interface, not a backwards-compatible extension. Alternatively explicit bounded chunk reads with independently defined integrity. CVSTOS grants constrain selected objects/revisions; MENTIS cannot acquire authority from metadata or model output. Remote transfers require separately authenticated network protocols.
