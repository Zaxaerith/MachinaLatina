# LVMEN Photonic R1 — Bounded approximate linear algebra
> FUTURE SCENARIO / DRAFT / NOT CANON · 2026-11-26. Conditional 2040–2045 photonic service study. No fabricated device, measured performance, native ISA or physical breakthrough assumed.

## 1. Electronic versus optical roles
LVMEN is an optional device family within Nova Memoria. Optical links carry encoded information; optical arithmetic attempts a physical transformation of modulated signals. Neither implies the other. A candidate matrix engine may use interferometric meshes or other calibrated linear optical structures; signed weights may require phase-sensitive or differential encoding. Loss, drift, noise, finite dynamic range, conversion and calibration are physical costs. Electronic memory, control, nonlinear activation, error handling and digital reference calculation remain essential. The R1 contract deliberately does not select a physical topology or claim arbitrary signed matrix multiplication is free.

## 2. Logical approximate matrix-vector service
An authorized host submits immutable W[M,K] and x[K], M,K each 1..64, tightly packed row-major big-endian signed i16 values restricted to -4096..4096. Decode each input as integer/4096 (exact rational, range -1..1); this fixed-point transport is neither M16 nor F32. Output candidate yhat[M] is signed i32, big-endian, decoded as integer/4096. Exact lengths 2*M*K, 2*K and 4*M octets. No hidden scale, implicit clipping, nonlinear operator, arbitrary tensor shape or raw device pointer. All buffers separate; explicit Memoria ownership or isolated copies. Validate shape, rights, encoding, calibration status and resource bounds before admission.

Reference y[i] = sum_j W[i,j]*x[j]/4096^2 using integer input codes. Signed 64-bit accumulation suffices (maximum absolute numerator 64*4096^2=1073741824); no intermediate rounding. Candidate output codes outside -262144..262144 are rejected. A declared tolerance is a nonnegative rational in output units, supplied before execution. In this bounded audited profile compute the independent digital reference for every component, then require absolute error <= tolerance for every component. A failed component rejects the entire private output; never publish partial accepted rows. Full reference checking can cost as much arithmetic as the original operation; this profile demonstrates numerical semantics, not acceleration. A later qualified workload might use statistical calibration or sampled audits, but cannot claim R1 full checking.

The host records device/profile, calibration revision, time and validity status, input identities, candidate output, reference arithmetic, error and result status. Calibration expiration or environmental limit violation denies admission or invalidates the result before publication. Exact physical calibration intervals and environmental limits depend on device profile; none are specified. No guarantee that a prior calibration bounds every later error. An accepted result meets this stated comparison only; it is not identical to MATRICES R1's ordered M16/F32 arithmetic, does not prove model correctness, and does not extend RATIO-I grammar.

## 3. Paper fixture
W = [[2048,2048],[4096,-4096]], x=[2048,1024], in integer codes. Decoded W=[[0.5,0.5],[1,-1]], x=[0.5,0.25]. Reference y=[0.375,0.25]. Candidate codes [1537,1022] yield [0.375244140625,0.24951171875]. Absolute errors [1/4096,2/4096]. Tolerance 2/4096 passes both; tolerance 1/4096 fails row 1 (zero-based) and rejects the whole result. Exact reference output codes [1536,1024]. Candidate output bytes 00 00 06 01 00 00 03 FE. These are invented candidate readings, not measurements. A calibrated digital fallback is a separate execution receipt; no silent replacement of a failed optical result.

## 4. Faults and authority
Private output follows Memoria staging; uncertain completion quarantines device buffers. Reject malformed encoding, calibration invalidity, unavailable reference, timeout, out-of-bounds output or tolerance failure. Cancellation stops future admissions, not guaranteed instantaneous physical stop. No optical signal confers resource authority. MENTIS selects only declared tools with existing authorization; it cannot label approximate computation exact. Device interface serialization, optical topology, ADC/DAC design, precision scaling, fault recovery, actual power and throughput remain open.
